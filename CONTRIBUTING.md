# Contributing to Deadline Watch

Thank you for helping people notice important dates.

1. Report bugs and user-requested enhancements using [GitHub Issues](https://github.com/phuongtt2a/super-productivity-deadline-watch/issues). Include reproduction steps, the installed app version, and expected behavior. Do not include personal task details or tokens.
2. For new features, create a focused feature branch and pull request. Bug fixes should reference the corresponding issue number.
3. Preserve the distinction between deadline, scheduled date, and recurring-series end date.
4. Keep the design accessible, keyboard-friendly, theme-aware, and responsive to 320px.
5. Test the package, date calculations, and browser views before PR review.
6. Use a squash merge only after checks pass. Publishing happens automatically after merging to main, never from an open PR.

See [development notes](docs/DEVELOPMENT.md).
